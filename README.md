# أكاديمية الحملة الأردنية الهاشمية الرياضية للأيتام

تطبيق React + Vite عربي باتجاه RTL لإدارة وعرض لاعبي الأكاديمية والمواعيد والإشعارات ولاعب الأسبوع، مع المصادقة والتخزين عبر Supabase.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء والنشر على Vercel

```bash
npm run build
npm run preview
```

إعدادات Vercel المعتادة لمشروع Vite:
- Framework Preset: `Vite`
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

## متغيرات البيئة المطلوبة

اضبط المتغيرين التاليين في Vercel (Production / Preview / Development بحسب بيئة النشر):
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

لا تضع `service_role` أو أي مفتاح سري في متغير يبدأ بـ `VITE_` أو في ملفات الواجهة. استمر باستخدام سياسات RLS المناسبة في Supabase.

## البيانات والتوافق

- يحتفظ التطبيق بالجداول الحالية: `players`, `training_sessions`, `academy_notifications`, `academy_settings`.
- يحتفظ بمساحة التخزين الحالية `academy-media`.
- لم تتم إضافة جداول أو تغيير أسماء أعمدة أو تنفيذ migrations.
- لا يتم تخزين ردود Supabase أو بيانات اللاعبين في Cache الخاص بـ Service Worker.
- صور الأكاديمية الرسمية محفوظة داخل `public/assets`.

## العمر وتاريخ الميلاد

تعرض الواجهة العمر المحسوب إذا كان تاريخ الميلاد متاحًا بالفعل في سجل اللاعب بأحد المفاتيح المعروفة، أو تعرض قيمة العمر الحالية إن وجدت. لم تتم إضافة عمود جديد لتاريخ الميلاد؛ يلزم فحص مخطط جدول `players` قبل أي تعديل على نموذج الإضافة أو قاعدة البيانات.

## ملاحظة أمنية

صلاحيات الإدارة يجب أن تبقى محكومة بمصادقة Supabase وسياسات RLS على مستوى قاعدة البيانات والتخزين. لا تعتمد على إخفاء عناصر الواجهة وحده كحاجز أمني.

## تحديث واجهة اللاعبين
- أصبحت صور اللاعبين تظهر داخل إطار دائري موحد مع الحفاظ على الصور الأصلية.
- يمكن الضغط على البطاقة أو استخدام Enter/Space لفتح ملف اللاعب.
- أضيفت إلى إعدادات الإدارة إمكانية تعريف حقول بيانات مخصصة وإزالتها من قائمة الحقول.
- إزالة تعريف حقل من الإعدادات لا تحذف القيم القديمة من قاعدة البيانات؛ تبقى البيانات محفوظة لتجنب فقدانها.
- لا يتطلب هذا التحديث إنشاء جداول أو أعمدة جديدة في Supabase.

## تحديث واجهة اللاعبين (نوفمبر 2026)
- بطاقات اللاعبين تعرض الصور بإطار مستطيل طولي متناسق مع الهوية البصرية.
- تظهر نجمة اختيار لاعب الأسبوع للمشرف فقط؛ ويُحفظ اللاعب المختار ضمن إعدادات الأكاديمية الموجودة في `academy_settings.content` دون إنشاء جدول جديد.
- قسم لاعب الأسبوع يعرض صورة واسم اللاعب المحدد تلقائيًا.
- ملف اللاعب يعرض الاسم والمركز والحقول الإضافية التي أدخلها المشرف، دون مؤشرات السرعة والمهارة الافتراضية.
- أزيلت أزرار الأسهم من واجهة الشرائح، وصُغّرت أزرار الهيدر ورتبت أفقيًا.
- أضيفت تحسينات ألوان الأيقونات والانتقالات مع احترام إعداد تقليل الحركة.

لم تتطلب هذه التعديلات تغيير مخطط Supabase أو أسماء الجداول أو سياسات الصلاحيات.
