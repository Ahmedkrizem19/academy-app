# أكاديمية الحملة الأردنية الهاشمية الرياضية للأيتام

تطبيق ويب عربي (RTL) لإدارة اللاعبين وجدول التمارين والمباريات.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

    python3 -m http.server 8000   # ثم افتح http://localhost:8000

لا يحتاج التطبيق إلى إنترنت أو مكتبات خارجية.

## الدخول
- **زائر:** عرض اللاعبين والمواعيد فقط.
- **أدمن:** كلمة المرور الافتراضية `1234`، وتُغيَّر من الإعدادات (4 أرقام).

## الإعدادات (للأدمن)
- اسم الأكاديمية والعبارة تحت الاسم وكلمة المرور
- رفع الصور بصيغة JPG: الشعار، خلفية واجهة الدخول، صورة التمارين، صورة لاعب الأسبوع
- عرض الشرائح: إضافة صور وتعليقات وترتيبها وحذفها، وتعديل الارتفاع وطريقة العرض ومدة الشريحة
- الإطارات والمظهر: استدارة الإطارات وألوانها وشكل وسماكة وحجم إطار صورة اللاعب
- رقم التواصل للاعب، مع خيار إظهاره للزائر (مخفي افتراضيًا)
- قائمة المراكز
- حقول بيانات اللاعب: إخفاء أي حقل أو إعادة تسميته أو إضافة حقول جديدة (نص / رقم / تاريخ)
- تصدير نسخة احتياطية واستيرادها، وإعادة ضبط التطبيق

## التثبيت على الشاشة الرئيسية
زر «تثبيت التطبيق على الشاشة الرئيسية» في واجهة الدخول وفي الإعدادات. يعمل عند نشر الملفات على رابط **https** (مثل GitHub Pages أو أي استضافة)، أو عبر `localhost`. لا يعمل التثبيت عند فتح `index.html` كملف مباشر. الملفان `manifest.webmanifest` و`sw.js` يجب أن يبقيا بجانب `index.html`.

## الميزات
- إضافة وتعديل وحذف اللاعبين والمواعيد، مع صورة JPG لكل لاعب
- مواعيد بدون تاريخ (يوم أو ملاحظة مثل «كل أحد وثلاثاء»)
- لاعب الأسبوع (نجمة في وضع الأدمن)
- الضغط على بطاقة اللاعب يعرض صورته كبيرة وبياناته أسفلها
- بحث وتصفية حسب المركز
- حفظ البيانات في المتصفح (localStorage)

## ملاحظة
كلمة المرور حماية واجهة فقط، والبيانات محلية لكل متصفح؛ للأمان الحقيقي والمزامنة بين الأجهزة يلزم خادم وقاعدة بيانات.
